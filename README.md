# Cold_tolerant_feed_crop_expansion
Code and workflow for assessing global expansion potential of cold-tolerant feed crops.

This repository contains scripts used for the study:

"Potential of Expanding Three Cold-Resistant Feed Crops to Offset Feed Requirements for Major Livestock"

## Overview

The workflow integrates:

1. MaxEnt ecological suitability modelling
2. Random Forest yield prediction
3. Spatial allocation scenarios
4. Feed deficit assessment


## Software
